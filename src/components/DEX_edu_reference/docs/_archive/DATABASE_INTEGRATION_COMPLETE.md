## 📋 Tables Created

### **1. signals**
- Stores trading signals generated by AI
- Columns: id, user_id, token, signal, confidence, reasoning, entry_price, stop_loss, take_profit, priority, valid, validation_errors, created_at, updated_at
- Indexes: user_id, token, signal, created_at, valid

### **2. trades**
- Stores executed trades
- Columns: id, user_id, signal_id (FK), token_in, token_out, amount_in, amount_out, entry_price, exit_price, stop_loss, take_profit, tx_hash, status, pnl, created_at, executed_at, closed_at
- Indexes: user_id, status, created_at, (token_in, token_out)

### **3. strategies**
- Stores user trading strategies
- Columns: id, user_id, name, type, config (JSONB), enabled, risk_level, created_at, updated_at
- Indexes: user_id, type, enabled, created_at

### **4. performance**
- Stores performance metrics per period
- Columns: id, user_id, period_start, period_end, total_trades, winning_trades, losing_trades, total_profit, total_loss, win_rate, profit_factor, sharpe_ratio, max_drawdown, created_at
- Indexes: user_id, period_start, period_end, created_at

### **5. bots**
- Tracks bot instances per user
- Columns: id, user_id, bot_id (unique), config (JSONB), status, started_at, stopped_at, created_at, updated_at
- Indexes: user_id, bot_id, status, created_at

## 🔧 Database Adapter

**Location:** `src/components/DEX/Proiect/backend/utils/dbAdapter.js`

**Features:**
- Sequelize-like interface pentru pg Pool
- Automatic column mapping (snake_case ↔ camelCase)
- Supports common operations: create, findAll, findOne, count, update, destroy
- Compatible cu existing service code

**Usage:**
```javascript
const db = require('../database');
const { createDbAdapter } = require('../utils/dbAdapter');
const dbAdapter = createDbAdapter(db);

// Merge adapter
db.Bot = dbAdapter.Bot;
db.Signal = dbAdapter.Signal;
db.Trade = dbAdapter.Trade;
db.Strategy = dbAdapter.Strategy;
```
